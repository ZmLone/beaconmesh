# BeaconMesh — Civic & Emergency Mutual Aid Ledger

Offline-first, community-verified neighborhood coordination for emergency medical, water, shelter, and road hazard alerts.

## Quick Browser Deploy (GitHub + Vercel)
1. Upload all files in this folder to a new GitHub repository.
2. Import that GitHub repository on [vercel.com/new](https://vercel.com/new) and click **Deploy**.
3. (Optional) Connect **Upstash Redis** from Vercel Storage / Marketplace for permanent multi-region persistence.
